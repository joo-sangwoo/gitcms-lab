# 이모저모 게시판

업무와 직접 관련은 없지만 함께 알아두면 좋은 것들을 모읍니다. 형식은 자유입니다.

## 자주 쓰는 명령

작업 중 반복해서 쓰게 되는 것들입니다.

```
git log --oneline -10
git status --short
gh run list --limit 5
```

`--oneline`은 커밋 하나를 한 줄로 보여 줍니다. 이력을 훑을 때 편합니다.

## 알아두면 좋은 것

- 커밋 메시지는 무엇을 왜 바꿨는지 적습니다
- 브랜치 이름은 소문자와 하이픈으로 짓습니다
- 생성물은 커밋하지 않습니다

## 자유 게시

주제와 무관한 이야기도 여기에 남깁니다. 이 섹션에 댓글을 달아 이어가면 됩니다.
